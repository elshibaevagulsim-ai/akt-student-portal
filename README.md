# akt-student-portal
АКТ студенттеріне арналған оқу порталы
Портал туралы

Бұл веб-сайт АКТ саласында білім алып жүрген студенттерге арналған. Мұнда оқу бағыттары, цифрлық құралдар, сабақ кестесінің үлгісі және студент туралы мәлімет енгізу формасы берілген.

Ақпараттық-коммуникациялық технологиялар ақпаратты жинау, сақтау, өңдеу және таратуға арналған заманауи құралдар мен әдістерді қамтиды. АКТ білім беру, ғылым, экономика және күнделікті өмірде кеңінен қолданылады.
Оқу бағыттары

Веб-әзірлеу
HTML және CSS көмегімен веб-беттердің құрылымы мен дизайнын жасау.

Деректермен жұмыс
Ақпаратты кестелерде сақтау, жүйелеу және талдау.

Цифрлық сауаттылық
Интернет ресурстарын қауіпсіз әрі тиімді пайдалану.

Пайдалы ресурстар

Веб-технологияларды үйренуге арналған сенімді оқу материалдары:

MDN Web Docs — HTML, CSS және веб-әзірлеу бойынша нұсқаулықтар.
GitHub — жобалар кодын сақтау және бөлісу платформасы.
Wix — сайтты визуалды редактор арқылы құрастыру платформасы.
